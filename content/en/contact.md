This site has no contact form. A form is only honest when something delivers the message, and this site has no mail
service configured, so it lists the channels that do work. For the library, GitHub is the place to write.

## On GitHub

- **A bug, a gap in the documentation or a feature request:**
  [open an issue](https://github.com/demonjic/Osirion.Blazor/issues/new/choose). The repository has a form for each of
  the three. Check the [open issues](https://github.com/demonjic/Osirion.Blazor/issues) first, and add to one if it is
  already there.
- **A question about using the library:** GitHub Discussions are not enabled on the repository, so open an issue and
  say it is a question. Other readers will find the answer there too.
- **A change you would like to make:** read the
  [contributing guide](https://github.com/demonjic/Osirion.Blazor/blob/master/CONTRIBUTING.md), then open a pull
  request. The [about page](/about) has the short version.

Messages on GitHub are public and subject to
[GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
Keep secrets, tokens and personal data out of an issue.

## A security problem

Do not describe a vulnerability in a public issue. Report it privately on GitHub instead: the repository's **Security**
tab has a **Report a vulnerability** button, which opens
[the private report form](https://github.com/demonjic/Osirion.Blazor/security/advisories/new). Only you and the
maintainers see the report. The [security policy](https://github.com/demonjic/Osirion.Blazor/security/policy) says
which versions get fixes and what a useful report contains.
